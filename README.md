# Introduction to EO programming

This repository contains code for the University of Edinburgh's [Introduction to Earth Observation](https://www.drps.ed.ac.uk/26-27/dpt/cxpgge11313.htm) course.
It is split in to two sessions:

* [Introduction to lidar](https://github.com/edinburgh-university-OOSA/pprs_programming/tree/main/lidar_intro)
* [Introduction to programming](https://github.com/edinburgh-university-OOSA/pprs_programming/tree/main/programming_intro)

There is a full README within each sub-directory.

## Introduction to lidar

This uses the [lidR](https://www.r-lidar.com/lidr) package in R to explore ground finding.


## Introduction to programming

This explores how python can be used to upscale plot data EO data through batch processing. it uses jupyter notebooks to handle DSM and DTM data derived from lidar.
